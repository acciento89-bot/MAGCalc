# MAGCalc

MAGCalc is a native iOS/iPadOS calculation aid for sizing diaphragm expansion vessels in heating systems.

## Scope

- Heating MAG sizing for water systems
- Pressure assistant from static height
- Pro: manual expansion sizing for glycol, solar and special media using manufacturer-specified volumetric expansion
- One-time Pro unlock via StoreKit
- German and English
- Offline, no account, no ads, no analytics

## Important

MAGCalc is a calculation aid for trained professionals. Manufacturer data, applicable standards, system design, safety equipment and commissioning measurements always take precedence.
